# Report data audit

Generated by `python scripts/audit_report_data.py --markdown` (static: JRXML field → bean property → SQL column; no database needed). Regenerate after changing a template, a report bean or a report view. CI runs the same script and fails on a template that runs its own SQL.

## Template fields with no supplying bean property

None is the goal: such a field renders as a permanently blank column. The table below is empty when every field resolves.

|---|---|---|---|
