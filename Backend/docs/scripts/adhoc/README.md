# Ad-hoc scripts — not part of the numbered migration run

Everything in `Backend/docs/scripts/V0xx__*.sql` is a migration: applied once,
in version order, on every environment (see `../../MIGRATION_RUNBOOK.md`).

The files in this folder are **not** that. They were written for one occasion,
carry no version, and are kept for the record. Do not run one unless you have
read it and know why you are running it. Several are destructive.

Four pre-runbook scripts that a numbered migration had superseded —
`PROPOSED_cleanup_leftover_tables.sql`, `alter_student_travel_ticket_costs_funding.sql`,
`alter_wafar_spending_beneficiary_type.sql` and `create_fin_received_whom_documents.sql` —
were removed on 23 Sep 2026. `V035` and `V058` carry their definitions; git history
keeps the files.
